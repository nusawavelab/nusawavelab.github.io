# Community

Nusawave Labs is an open knowledge hub for metocean analytics.

## Get Involved

- **Request a tutorial topic** — open an [issue](https://github.com/nusawave-labs/nusawave-labs.github.io/issues) with your use case
- **Fix something** — PRs welcome for typos, broken links, or improved explanations
- **Contribute a notebook** — see the [README](https://github.com/nusawave-labs/nusawave-labs.github.io#contributing) for guidelines
- **Follow for updates** — [Nusawave on LinkedIn](https://www.linkedin.com/company/nusawave)
