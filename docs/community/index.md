# Community

Monsun Labs is an open knowledge hub for metocean analytics.

## Get Involved

- **Request a tutorial topic** — open an [issue](https://github.com/monsun-labs/monsun-labs.github.io/issues) with your use case
- **Fix something** — PRs welcome for typos, broken links, or improved explanations
- **Contribute a notebook** — see the [README](https://github.com/monsun-labs/monsun-labs.github.io#contributing) for guidelines
- **Follow for updates** — [Monsun on LinkedIn](https://www.linkedin.com/company/monsunic)
